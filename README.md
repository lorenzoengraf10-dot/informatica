# Informática — Centro de aprendizaje autodidacta

Repositorio para aprender desarrollo de software (código, organización, testeo,
control de versiones) de forma autodidacta y sin apuro.

## Empezar acá

**[`aprender/index.html`](aprender/index.html)** es una aplicación de 27
lecciones interactivas de HTML, CSS y JavaScript con editor de código en vivo
y solución sugerida en cada una. Está pensada primero para el celular
(mobile-first) y se puede instalar como app en el teléfono y usar sin internet;
en la computadora aprovecha el ancho. Se abre en el navegador, sin instalar
nada, y guarda tu progreso solo. Ver `aprender/README.md` para el detalle de
cómo usarla y el temario completo.

La idea de fondo: el emprendimiento real **Productos Patagónicos**
(repositorio [`productosoatagonicos`](https://github.com/lorenzoengraf10-dot/productosoatagonicos))
sirve como caso de estudio de uso interno — nunca se ofrece como servicio a terceros
mientras se está en etapa de aprendizaje. Acá, en `informatica`, viven las
lecciones y los proyectos de práctica más chicos y sueltos.

## Estructura

```
informatica/
  aprender/                 aplicación de 27 lecciones interactivas, mobile-first (empezar acá)
  ROADMAP.md                plan general de aprendizaje, por fases
  BITACORA.md               registro personal: qué se probó, qué se aprendió, cuándo
  proyectos-practica/
    pagina-pruebas/          para romper cosas sin miedo: HTML, CSS, JS, DOM, formularios
    blog-personal/           para practicar publicar contenido, estructura semántica y SEO
```

## Cómo se usa este repositorio

1. Arrancar por `aprender/` para los fundamentos de HTML/CSS/JS con ejercicios guiados
   y solución sugerida para cada uno.
2. Cada vez que se prueba algo nuevo por fuera de una lección (una función, un
   concepto de DNS, CDN, etc.), se anota en `BITACORA.md`: fecha, qué se probó,
   qué funcionó o no, y por qué.
3. Los proyectos de `proyectos-practica/` son intencionalmente simples. No tienen
   que quedar "perfectos": son para entender cómo funciona cada pieza por fuera
   de la estructura guiada de `aprender/`.
4. El `ROADMAP.md` se va tildando a medida que se avanza. No hay fecha límite.

## Relación con Productos Patagónicos

- El panel de gestión real (uso interno, datos del negocio) vive en el otro
  repositorio, no acá, porque es una herramienta de trabajo, no un experimento.
- Acá se prueban ideas nuevas primero (por ejemplo, una función o un estilo) antes
  de llevarlas al panel de gestión, para no arriesgar los datos reales del negocio
  mientras se aprende.
